# Code de conduite

J'applique à OpenFSP le **Contributor Covenant, version 2.1**, sans modification.

Le texte français officiel fait foi pour ce projet :
<https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/>

## Portée

Le code s'applique dans tous les espaces du projet (dépôts, tickets, pull requests, fils
d'ADR, discussions) et lorsqu'une personne représente le projet dans un espace public.

## Signalement

Les comportements abusifs, harcelants ou autrement inacceptables se signalent à
**conduct@karakosystems.com**, en français, en créole haïtien ou en anglais.

Je traite les signalements en tant qu'éditeur du projet
([GOVERNANCE.md 1](GOVERNANCE.md#1-porteur)), rapidement et équitablement, et je protège la
vie privée et la sécurité de la personne qui signale.

Les suites que je donne suivent l'échelle du Contributor Covenant : correction,
avertissement, bannissement temporaire, bannissement permanent.

Si votre signalement me concerne, écrivez à **dev@karakosystems.com**, où une autre personne
de Karako Systems le reçoit.

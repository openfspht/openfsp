# Code de conduite

OpenFSP adopte le **Contributor Covenant, version 2.1**, sans modification.

Le texte français officiel fait foi pour ce projet :
<https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/>

Nous renvoyons au texte officiel plutôt que d'en recopier une variante : une version locale
qui dérive de l'original crée deux règles là où il n'en faut qu'une.

## Portée

Le code s'applique dans tous les espaces du projet (dépôts, tickets, pull requests, fils
d'ADR, discussions) et lorsqu'une personne représente le projet dans un espace public.

## Signalement

Les comportements abusifs, harcelants ou autrement inacceptables se signalent à
**conduct@karakosystems.com**. Vous pouvez écrire en français, en créole haïtien ou en
anglais.

Tous les signalements sont examinés rapidement et équitablement. La vie privée et la
sécurité de la personne qui signale sont protégées.

Les suites données suivent l'échelle prévue par le Contributor Covenant : correction,
avertissement, bannissement temporaire, bannissement permanent.

Les signalements sont traités par l'éditeur du projet, tel que défini dans
[GOVERNANCE.md §1](GOVERNANCE.md#1-porteur). Si votre signalement concerne l'éditeur
lui-même, écrivez à **dev@karakosystems.com**, où il sera reçu par une autre personne de
Karako Systems.
